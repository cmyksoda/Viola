Mode for new chats

Remote

With Tailscale (recommended), the link works from anywhere, over HTTPS when your tailnet has certificates turned on. Without it, Viola uses your home network, so the phone has to be on the same Wi-Fi and the link isn't encrypted, so only use it on a network you trust. Either way the link carries a secret token that can control this computer, so only send it to yourself.

Welcome to Viola

Viola runs Claude Code for you and keeps your chats in one window. It needs two things before the first message.

Claude Code

curl -fsSL https://claude.ai/install.sh | bash

An Anthropic API key

Make one at console.anthropic.com under API keys. It stays on this computer, in Viola's own settings file.

Admin key, if you want the exact balance

You type your balance in once and Viola counts down from it. With an admin key, it counts down by what Anthropic actually billed, including spending outside Viola.
